# דראפט NBA ← אירופה וישראל

אפליקציה (אתר + אפליקציה לטלפון, PWA) למעקב אחרי כל שחקני דראפט ה-NBA מאז 1980:
מי שיחק ב-NBA ואז הגיע לאירופה, מי הגיע מאירופה ל-NBA, ומי מהם שיחק בישראל ובאיזו קבוצה.

## מה יש באפליקציה

- **כל הדראפטים 1980–2025 מובנים** (3,831 בחירות), כולל מספר משחקי ה-NBA של כל שחקן ועונות ה-NBA שלו,
  כך שאפשר לראות מיד מי שיחק ב-NBA.
- **דף שחקן:**
  - קבוצות באירופה, עם עונה, קבוצה ומדינה.
  - סימון אם הגיע לישראל, ואם כן לאיזו קבוצה, באיזו עונה ובאיזו ליגה.
  - הערות.
  - קישורים מהירים ל-Basketball-Reference, RealGM, Proballers, Eurobasket ומנהלת הליגה לבדיקה.
- **מסלול אוטומטי:** לפי עונות ה-NBA והעונות שהוזנו, האפליקציה קובעת מסלול: *מה-NBA לאירופה*,
  *מאירופה ל-NBA*, *הלוך ושוב* או *אירופה בלבד*. אפשר גם לקבוע את המסלול ידנית, למשל *NBA בלבד*.
  ישראל נחשבת לאירופה לצורך המסלול.
- **השלמה אוטומטית לקבוצות:**
  - כל קבוצות ליגת העל והלאומית, קבוצות הליגה הארצית (צפון ודרום), וקבוצות היסטוריות.
  - כ-340 מועדונים באירופה.
  - כל קבוצה חדשה שמקלידים נכנסת להשלמה בפעם הבאה.
- **סטטיסטיקה לכל דראפט:**
  - נבחרים ומי שיחק ב-NBA.
  - כמה עברו מה-NBA לאירופה, כמה הגיעו מאירופה ל-NBA, וכמה הלכו הלוך ושוב.
  - כמה הגיעו לישראל.
  - פילוח לפי סיבוב, קבוצות בישראל, מדינות באירופה ועונת ההגעה לאירופה.
  - אחוז השחקנים שכבר נבדקו.
- **סטטיסטיקה כללית:** גרף לפי שנת דראפט וטבלת השוואה בין כל הדראפטים.
- **עמוד "בישראל":** כל השחקנים שהגיעו לישראל, מקובצים לפי קבוצה.
- **דראפט ידני לגמרי:** יוצרים דראפט (למשל 2026) ומוסיפים שחקנים אחד-אחד, או מדביקים רשימה שלמה
  מ-Excel או מ-Basketball-Reference. אפשר גם להוסיף שחקנים לדראפט קיים ולערוך את הפרטים של כל שחקן.
- **עבודה מהירה:** מכל שחקן עוברים לשחקן הבא או לשחקן הבא שעוד לא נבדק. השמירה אוטומטית.
- **סנכרון בין הטלפון למחשב** דרך Gist פרטי ב-GitHub (לא חובה). צריך טוקן עם הרשאת `gist` בלבד.
- **גיבוי ויצוא:** יצוא JSON, ייבוא עם מיזוג, ויצוא CSV לאקסל.
- **עיצוב בסגנון NBA:**
  - מצב בהיר בגווני פרקט ומצב כהה בסגנון אולם.
  - לוח תוצאות בכל מסך, וגופנים Bebas Neue ו-Rubik שמותקנים בתוך האפליקציה.
  - מספרי בחירה בצורת גופייה וצבעי כל קבוצות ה-NBA.
  - דף שחקן בסגנון כרטיס אספנים, עם ציר זמן של הקריירה.
  - כל עשור מקבל צבע משלו, ויש דגלים למדינות.
- האפליקציה עובדת גם בלי אינטרנט.

## הפעלה

אין צורך בבנייה: זה אתר סטטי.

```bash
npm start          # שרת מקומי על http://localhost:8080
npm test           # בדיקות לוגיקה
```

### פרסום לאינטרנט (GitHub Pages)

1. ב-GitHub: **Settings → Pages → Source: GitHub Actions**.
2. אחרי מיזוג ל-`main`, ה-workflow `.github/workflows/pages.yml` מריץ את הבדיקות ומפרסם את האתר.
3. בטלפון פותחים את הכתובת ומוסיפים למסך הבית:
   - **אייפון:** ב-Safari לוחצים על כפתור השיתוף ובוחרים "הוסף למסך הבית".
   - **אנדרואיד:** ב-Chrome פותחים את התפריט ובוחרים "התקנת אפליקציה".

### אפליקציית אנדרואיד (APK)

האפליקציה נארזת כ-APK בעזרת [Capacitor](https://capacitorjs.com).
- **הורדה:** [nba-draft-europe.apk](https://github.com/danielf2306/NBAPlayersInEuropeAndIsrael/releases/latest/download/nba-draft-europe.apk), הגרסה האחרונה בעמוד ה-Releases.
  - מורידים את הקובץ בטלפון, פותחים אותו ומאשרים "התקנה ממקורות לא ידועים".
- **בנייה אוטומטית:** ה-workflow `.github/workflows/android.yml` בונה APK חתום.
  - בכל PR ה-APK נשמר כ-artifact.
  - בכל מיזוג ל-`main` נוצר Release חדש.
- **עדכונים:** כל גרסה חתומה באותו מפתח (`android/app/sideload.keystore`), ולכן מתקינים גרסה חדשה מעל הקיימת והנתונים נשמרים.
  - זה מפתח להתקנה ידנית בלבד, לא ל-Google Play.
  - אפשר להחליף אותו במפתח פרטי דרך משתני הסביבה `ANDROID_KEYSTORE_PATH`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS` ו-`ANDROID_KEY_PASSWORD`.
- **נתונים:** הסרת האפליקציה מוחקת את הנתונים שנשמרו בה. כדאי להפעיל סנכרון או לייצא גיבוי. באפליקציה, יצוא קבצים נפתח בחלון השיתוף של אנדרואיד (Drive, WhatsApp, קבצים).
- **בנייה מקומית:** צריך JDK 21 ו-Android SDK. מריצים `npm ci` ואז `npm run android:apk`. ה-APK נוצר ב-`android/app/build/outputs/apk/release/`.
- **אייקונים ומסך פתיחה:** נוצרים מחדש עם `node tools/android-assets.mjs`.

## נתונים

| קובץ | מקור |
|---|---|
| `data/drafts.json` | Basketball-Reference דרך [sumitrodatta/bball-reference-datasets](https://github.com/sumitrodatta/bball-reference-datasets). לעדכון: `npm run build:drafts` |
| `data/teams-israel.json` | ליגת העל ולאומית לעונת 2026/27, ליגה ארצית (צפון ודרום) לפי עונת 2025/26, וקבוצות היסטוריות. רשימת הארצית חלקית; קבוצה חסרה פשוט מקלידים, והיא תישמר להשלמה |
| `data/teams-europe.json` | מועדונים מרכזיים בכ-40 מדינות |

הנתונים שלך (הסימונים, הדראפטים הידניים והעריכות) נשמרים בדפדפן (`localStorage`), ובנוסף ב-Gist אם הפעלת סנכרון.
הם לא נשמרים בריפו.

## מבנה

```
index.html, css/style.css, css/fonts.css
fonts/            גופנים (רישיון OFL)
js/nba.js         צבעי קבוצות NBA, דגלים, אלמנטים גרפיים
js/app.js         ניתוב ומסכים
js/model.js       לוגיקה טהורה: חישוב מסלול, סטטיסטיקה, מיזוג, פענוח הדבקה (נבדק ב-tests/)
js/store.js       מצב ושמירה מקומית
js/sync.js        סנכרון Gist
js/teams.js       השלמה אוטומטית לקבוצות
sw.js             עבודה בלי אינטרנט. לאחר שינוי בקבצים יש להעלות את VERSION
js/native.js      שילוב עם אפליקציית האנדרואיד (שיתוף קבצים, סרגלי מערכת)
android/          פרויקט האנדרואיד (Capacitor)
tools/build-web.mjs  מעתיק את האתר ל-www/ לצורך בניית ה-APK
tools/build_drafts.py
```
